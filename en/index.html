LiteRaceSegNet

A small CNN that segments road damage (potholes) as a binary mask. The full model has about 0.125M parameters. I wanted to see how much of the small damage regions and their edges a model this size can keep.

Model

Code: seg/core/lightweight_race.py

StageLayersChannelsScale
stem3×3 conv (stride 2) + depthwise separable conv241/2
detailLiteIRBlock × 2241/2
down1LiteIRBlock × 2 (stride 2)481/4
down2LiteIRBlock × 2 (stride 2)961/8
contextLiteASPP (dilation 1, 2, 4 + global pooling)961/8
boundary headedge logit from the detail and context features11/2
fusedetail, context and edge logit concatenated and fused961/2
head1×1 conv, then upsampled to the input size21
aux head1×1 conv on the down1 output (training only)21

LiteIRBlock is a simplified version of the MobileNetV2/V3 inverted-residual block, written for this project.

The boundary head predicts an edge logit from the detail features and the upsampled context features. The detail features are multiplied by 1 + sigmoid(edge) (boundary gate), and the edge logit goes into the final fusion as one extra channel (boundary-logit fusion).

Training setup

Input size256 × 384
Batch / epochs4 / up to 60, early stopping with patience 12
OptimiserAdamW, lr 3.2e-4, weight decay 2e-4, poly schedule
LossCE 1.0 + Dice 0.35 + auxiliary 0.2 + boundary 0.1
Data2,400 training pairs, 10 validation pairs, 10 test images
HardwareAWS GPU instance, AMP, seed 42

Config: seg/config/v13_ablation/v13_full_reference.yaml

Run

pip install -r requirements.txt
python scripts/smoke_check_literace.py      # builds the model and runs a forward pass
python seg/train_literace.py --config seg/config/pothole_binary_literace_train.yaml
bash scripts/run_v13_ablation_matrix.sh     # trains the 7 variants and writes the summary

Training needs your own image and mask pairs laid out as described in datasets/pothole_binary/README_DATASET_LAYOUT.md. The .bat files in the root do the same steps on Windows.
