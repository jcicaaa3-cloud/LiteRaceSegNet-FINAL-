LiteRaceSegNet

도로 손상(포트홀)을 이진 마스크로 분할하는 작은 CNN입니다. 전체 모델의 파라미터는 약 0.125M입니다. 이 크기의 모델로 작은 손상 영역과 그 가장자리를 어디까지 살릴 수 있는지 보려고 만들었습니다.

모델

코드: seg/core/lightweight_race.py

단계구성채널해상도
stem3×3 conv (stride 2) + depthwise separable conv241/2
detailLiteIRBlock × 2241/2
down1LiteIRBlock × 2 (stride 2)481/4
down2LiteIRBlock × 2 (stride 2)961/8
contextLiteASPP (dilation 1, 2, 4 + global pooling)961/8
boundary headdetail과 context 피처로 에지 로짓 예측11/2
fusedetail + context + 에지 로짓을 이어 붙여 융합961/2
head1×1 conv 후 입력 크기로 업샘플21
aux headdown1 출력에 1×1 conv (학습 때만 사용)21

LiteIRBlock은 MobileNetV2/V3의 inverted residual 블록을 이 프로젝트에 맞게 단순화해서 구현한 것입니다.

boundary head는 detail 피처와 업샘플한 context 피처를 받아 에지 로짓을 예측합니다. detail 피처에는 1 + sigmoid(edge)를 곱하고(boundary gate), 에지 로짓은 한 채널로 마지막 융합에 같이 넣습니다(boundary-logit fusion).

학습 설정

입력 크기256 × 384
배치 / 에폭4 / 최대 60, patience 12로 조기 종료
옵티마이저AdamW, lr 3.2e-4, weight decay 2e-4, poly 스케줄
손실CE 1.0 + Dice 0.35 + 보조 0.2 + 경계 0.1
데이터학습 2,400쌍, 검증 10쌍, 테스트 10장
환경AWS GPU 인스턴스, AMP, seed 42

설정 파일: seg/config/v13_ablation/v13_full_reference.yaml

지연 시간은 CUDA, 입력 256×384, 이미지 1장 기준입니다. 검증 임계값은 0.60입니다.

검증 이미지가 10장이고 변형마다 한 번씩만 학습했기 때문에, boundary-logit fusion의 0.003 같은 작은 차이는 실제 효과로 보면 안 됩니다. 크게 떨어진 건 LiteASPP와 보조 손실을 뺐을 때입니다. 슬림 백본은 파라미터가 절반 이하인데 mIoU는 거의 같습니다.

추론 결과

경계선만 그린 버전 · 요약 카드 · 원본 마스크와 후처리 마스크

요약 카드는 seg/infer_service_visual.py가 마스크에서 손상 면적 비율과 영역 수를 계산해 만든 것입니다.

실행

pip install -r requirements.txt
python scripts/smoke_check_literace.py      # 모델 생성 후 순전파 1회
python seg/train_literace.py --config seg/config/pothole_binary_literace_train.yaml
bash scripts/run_v13_ablation_matrix.sh     # 변형 7개 학습 후 요약 출력

학습하려면 datasets/pothole_binary/README_DATASET_LAYOUT.md대로 배치한 이미지·마스크 쌍이 필요합니다. 루트의 .bat 파일은 같은 과정을 Windows에서 실행합니다.
